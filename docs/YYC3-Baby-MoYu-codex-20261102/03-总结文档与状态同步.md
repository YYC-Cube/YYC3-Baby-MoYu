## 遇到的问题与解决

| 问题 | 解决方案 | 经验 |
| ---- | ---- | ---- |
| 初始 tsc/lint 大规模缺包 | `bun install --frozen-lockfile` | 审计前先确保依赖完整 |
| `docs` 工程被根 tsc 编译 | 排除 `docs` | 单仓多工程必须边界隔离 |
| `bun run test` 执行 Vitest 工程 100 失败 | 忽略 `docs/**` | 测试运行器范围要显式声明 |
| e2e 缺 Chromium | `bunx playwright install chromium` | CI 已有安装步骤，本地需补 |
| `bun audit` 404 | 记录限制，改用已知通告升级 | 审计源不可用不能假装通过 |
| 大小写重命名在 macOS 无效 | 临时名两步重命名 | 跨平台路径规范需显式处理 |
