## 一、拆分说明

原《智能❤️AI项目- 全栈完整内容.md》为 12 000 余行的单体文档，章节跨度大、检索成本高。本目录按原文十二个章节拆分为独立文档，正文逐行保真迁移，仅在每篇补齐团队标准标头与标尾。

| 项目 | 说明 |
| ---- | ---- |
| 拆分依据 | 原文「二、目录」中的十二章节结构 |
| 拆分方式 | 按章节标题边界切分，正文零改写 |
| 单篇规范 | 标准 YAML 标头 + 标语块 + 核心理念 + 变更历史 + 品牌页脚 |
| 原文归档 | `_archive/原始完整版-智能AI项目-全栈完整内容.md`（仅作溯源） |
| 覆盖校验 | 原文第 36–12087 行正文全部落入 12 篇文档，无遗漏 |
