### B.2 边界条件与异常场景清单

| 类别 | 场景 | 期望 |
| ---- | ---- | ---- |
| 输入长度 | 记录标题/内容、聊天消息（4000 上限已设）、故事关键词 | 一律有上限，超限 400/413 且带中文提示 |
| 编码 | emoji、全角标点、RTL、中文姓名 30 字 | 不乱码、不截断错误、SQL 参数化无误 |
| 日期 | `birth_date` 未来日期、1900 前、非法格式 | 400（当前未见校验，建议补） |
| 枚举 | `gender`/`type`/`status`/`priority` 非法值 | 400，且不落库 |
| 并发 | 同一娃并发写 20 条记录 | 500 不出现；SQLite `busy_timeout=8000` 生效 |
| 重复 | 重复邮箱注册 | 静默 no-op 或 409，且响应不可区分为「已存在」（防枚举） |
| 大文件 | 10 MB 图 / 25 MB 音频 / 50 MB JSON | 413，服务端不 OOM |
| 会话 | access 过期 → 自动刷新 → 重试；refresh 也过期 | 前者透明重试成功，后者跳登录 |
| 多标签 | 两标签并发触发 401 刷新 | 仅一次刷新（`auth-fetch` 已有并发锁用例） |
| 资源 | 删除孩子（级联删记录/作业） | 列表与统计同步减少，无孤儿行 |
| 时区 | 服务器 UTC / 浏览器 +08:00 | 「今天/昨天」显示正确（`formatDate` 有单测） |

| 门禁 | 通过条件 |

**失败判定（任一即阻断）**

1. 任一 P0 用例失败；
2. 认证/租户隔离出现任何 200 泄漏（他人数据可见/可写）；
3. 数据写入后重启丢失；
4. 构建或类型检查失败；
5. 出现新的 Critical 依赖漏洞且无处置结论；
6. 视觉基线差异 > 2% 且未说明原因（`maxDiffPixelRatio: 0.02`）。
