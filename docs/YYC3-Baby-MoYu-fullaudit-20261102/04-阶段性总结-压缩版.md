## 4. 关键决策（不可回退的约定）

1. **AI 不得假装**：无密钥必须走示例并在 SSE 首帧声明 `demo:true`；页面显式标注「演示模式」。
2. **文档 = 事实源**：能力矩阵按代码写；`.env.example` 必须覆盖所有读取点。
3. **数据双轨结束**：课表/日程/互动/视频/评估全部服务端持久化；游客降级仅本地，登录后自动迁移。
4. **单实例约束**：限流为进程内、事务/AgenticCore 为进程内；多副本前必须先换 Redis。
5. **默认安全**：数据 API 一律登录 + 租户隔离；Cookie httpOnly + CSRF Origin 校验；匿名端点必须限流+限体积。
6. **可回退**：数据库驱动、AI 供应商、容器镜像 tag 均有回退路径。
